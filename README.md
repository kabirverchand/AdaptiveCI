# AdaptiveCI
Code accompanying the paper "Adaptive confidence intervals with missing data".  The plots in Section 5.1 can be found in the notebook "Gaussian-CI.ipynb", whereas the data analysis in Section 5.2 can be found in "Aymara.ipynb" and the analysis in Section 5.3 can be found in "SmokingBirthweight.ipynb".

Implementations of all of the confidence intervals developed in the paper can be found in "confidence_intervals.py".
